# Contributing to a/foodusa

Share a Post or Artifact from the Wall, https://abstracts.co/a/foodusa/wall, or open a pull request here. Maintainers (starting with @BY-ALT-CTRL) accept or close it.

Use the Artifact cube for a bundle in `artifacts/<id>/`; check its title and cover, then Post. Text, photos, links and notes stay Discussions. Configuration uses native repository writer tools.
